

##Функционал

- ✅ Создание, редактирование и удаление задач
- ✅ Уникальный ID для каждой задачи (UUID)
- ✅ Отметка о выполнении
- ✅ Отображение даты создания
- ✅ Адаптивный дизайн с поддержкой светлой/тёмной темы
- ✅ Валидация форм при создании задачи

##Технологии

- Flutter (Dart)
- `uuid` — генерация уникальных идентификаторов
- `intl` — форматирование дат
- Material Design 3

##Запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/ВАШ_НИКНЕЙМ/todo_app.git

# Перейдите в папку проекта
cd todo_app

# Установите зависимости
flutter pub get

# Запустите приложение
flutter run
